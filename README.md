# Analisis Kesesuaian Lahan Industri Kabupaten Karanganyar

WebGIS Analisis Kesesuaian Lahan Industri Kabupaten Karanganyar merupakan sistem informasi geografis berbasis web yang dikembangkan untuk menyajikan hasil analisis spasial kesesuaian lahan bagi pengembangan kawasan industri di Kabupaten Karanganyar. Peta interaktif ini dibuat untuk memenuhi tugas mata kuliah **Sistem Informasi Perencanaan (SIP)**.

## Lihat Peta

🌐 [Buka WebGIS](https://wqwqq21221.github.io/SIP-KLIKaranganyar/)

## Informasi Peta

WebGIS ini menyajikan informasi spasial terkait kesesuaian lahan industri di Kabupaten Karanganyar dengan mempertimbangkan beberapa aspek, yaitu:

- Kesesuaian pola ruang.
- Penggunaan lahan eksisting.
- Aksesibilitas terhadap jaringan transportasi.
- Ketersediaan infrastruktur pendukung, meliputi air baku, listrik, dan telekomunikasi.
- Kedekatan terhadap pusat kota dan kawasan permukiman.
- Kondisi multi-bahaya.
- Kemiringan lereng.

## Fitur WebGIS

- Peta interaktif kesesuaian lahan industri Kabupaten Karanganyar.
- Pengaturan tampilan layer dan legenda peta.
- Pencarian lokasi berdasarkan nama tempat.
- Informasi koordinat lokasi pada peta.
- Tabel atribut untuk melihat informasi data spasial.
- Fitur zoom, kembali ke tampilan awal, full screen, dan cetak peta.

## Metode dan Teknologi

WebGIS ini dikembangkan menggunakan beberapa perangkat dan teknologi berikut:

- **QGIS** – Pengolahan data spasial dan penyusunan peta analisis.
- **qgis2web** – Publikasi peta QGIS menjadi aplikasi WebGIS.
- **OpenLayers** – Menampilkan dan mengelola peta interaktif berbasis web.
- **Netlify** – Hosting dan publikasi WebGIS agar dapat diakses secara daring.
- **GitHub** – Penyimpanan dan pengelolaan berkas proyek.

## Tujuan Pengembangan

Pembuatan WebGIS ini bertujuan untuk menyajikan informasi hasil analisis kesesuaian lahan industri Kabupaten Karanganyar secara interaktif dan informatif, sehingga dapat memudahkan pengguna dalam memahami persebaran serta karakteristik kesesuaian lahan sebagai informasi pendukung perencanaan wilayah.
